# E-003 — Production Restore Validation

**الحالة: OPEN — لم تُنفَّذ استعادة إنتاج مثبتة في الأدلة المتاحة.** هذه ورقة تنفيذ وتوثيق، وليست إثبات نجاح. المرجع المحلي السابق [`../evidence/isolated-database-restore.json`](../evidence/isolated-database-restore.json) موسوم `PASS_LOCAL_SYNTHETIC_ONLY`؛ لا يُقبل بدل نسخة إنتاج حقيقية أو Recovery Point موثّق.

## متطلبات ما قبل التنفيذ

- [ ] موافقة صاحب الصلاحية على تجربة الاستعادة **في بيئة معزولة فقط**، وتحديد المنفّذ ونافذة التنفيذ.
- [ ] إثبات هوية قاعدة إنتاج التطبيق وموفّرها وربط النسخة بها؛ لا تسجّل أي مفاتيح أو أسرار في المستودع.
- [ ] تحديد نسخة إنتاج حقيقية / Recovery Point بمعرّف الموفّر، توقيت UTC، نطاق البيانات، مدة الاحتفاظ، وبصمة SHA-256 إن كانت متاحة.
- [ ] تجهيز وجهة استعادة منفصلة لا تشارك production bindings أو الكتابة المجدولة؛ تعطيل مهام الكتابة والإشعارات/التكاملات الخارجية في البيئة المعزولة.
- [ ] تأكيد خطة تنظيف آمنة للبيانات الحساسة بعد التجربة، وتخزين سجل التنفيذ في موقع خاص مع رابط محدود الصلاحيات فقط.

## إجراء التشغيل (لمن يملك صلاحية الموفّر)

1. سجّل مرجع النسخة وتوقيت نقطة التعافي، ثم التقط أعداد/بصمات مرجعية قابلة للمقارنة ضمن سياسة الخصوصية. لا تنشر بيانات المستخدم أو النسخة نفسها في Git.
2. استخدم إجراء موفّر قاعدة البيانات المعتمد لنسخ **نقطة الإنتاج المحددة إلى وجهة اختبار مستقلة**؛ لا تستعد فوق الإنتاج ولا تغيّر قاعدة الإنتاج أو إعدادات النشر الحي.
3. احتفظ بمراجع job / operation ID وسجل البداية والنهاية ونتيجة الاستعادة، بعد حجب الأسرار والبيانات الحساسة.
4. نفّذ اختبارات سلامة المخطط والفهارس وعدد السجلات والجداول الحرجة (الإعدادات، المحافظ، الصفقات، النقد، وتاريخ التوقعات). إن كانت النسخة SQLite، نفّذ `PRAGMA integrity_check;` و`PRAGMA foreign_key_check;` على **النسخة المعزولة**؛ عند اختلاف المحرك استخدم الفحوص المكافئة المعتمدة.
5. قارِن بصمات/أعداد المصدر عند نقطة الاستعادة بما في الوجهة؛ وثّق فروق التوقيت أو الكتابات اللاحقة دون محاولة محوها. اختبر قراءة التطبيق ضد الوجهة المعزولة فقط مع تعطيل الكتابات والجدولة؛ أجرِ smoke tests للإعدادات والمحافظ والصفقات والتوقعات.
6. سجّل مدة الاستعادة الفعلية وتقدير RPO/RTO بناءً على الأوقات المقاسة، والفشل/الاستثناءات، وتأكيد عدم المساس بالإنتاج.
7. لا تعلن PASS إلا بعد فحص أدلة التنفيذ والمطابقة بواسطة المراجع المخوّل؛ أرفق روابط أدلة خاصة أو مراجع موثّقة لا تكشف بيانات حساسة.

**قرار البوابة الحالي: `E-003 = OPEN`.** لا يُقبل `PASS_LOCAL_SYNTHETIC_ONLY` ولا تجهيز هذا النموذج كدليل إغلاق. عند اكتمال التنفيذ حدّث [مصفوفة الإغلاق](closure-matrix.md) وأرفق الأدلة قبل طلب E-004.
