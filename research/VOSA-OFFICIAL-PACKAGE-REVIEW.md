## اختبار حالات حدية على النموذج المرجعي (Python، نُفِّذ فعلاً)
| الحالة | النتيجة | الحكم |
|---|---|---|
| `NaN` في range_gate | **PASS** | عيب: مخالف لمبدأ «البيانات غير الصالحة ≠ مرور» |
| نص غير رقمي `"abc"` | استثناء ValueError | عيب: ينهار بدل SUSPEND |
| `True` كقيمة رقمية | PASS | عيب: bool يُقبل كرقم |
| `inf` | KILL | سليم |
| `None` | SUSPEND | سليم |
| KILL بلا دليل | استثناء | يختلف عن نسختنا (SUSPEND آمن) |
| خط أنابيب بلا بوابات | PASS | عيب: لا بوابات = لا مراجعة |
| `required` مع NaN | PASS | عيب |
| إصدار مكرر / أب مجهول في DAG | يُرفض | سليم |
| تعديل حدث في السلسلة | يُكتشف | سليم |
| حذف آخر حدث في السلسلة | **لا يُكتشف** | عيب: يلزم «رأس» خارجي |
| بصمة الحدث | تضم `time`/`uuid` | غير حتمية |

## ما أُخذ من المعرفة وطُوِّر في TypeScript (`mizan-v45/lib/vosa/`)
| الفكرة | الملف | التحسين على المرجع |
|---|---|---|
| سلسلة تدقيق مشفّرة | `chain.ts` + `sha256.ts` | SHA-256 حتمي (بلا time/uuid)، يرفض NaN، `head()` للتحقق من الحذف الأخير، مطابق لـ node:crypto |
| سلالة إصدارات غير قابلة للتغيير | `lineage.ts` (`VosaLineage`) | + إصدارات تتزايد فقط، إصدار صحيح موجب، idempotent لنفس الحمولة |
| منع الإحياء (No Resurrection) | `lineage.ts` (`VosaRunLedger`) | KILL نهائي داخل التشغيل؛ الإصدار الجديد من الصفر؛ المجهول غير قابل للترتيب |
| ثغرة اكتشفتها أثناء الدمج | `engine.ts` | رفض الظرف غير الصالح (SUSPEND) لم يكن يُسجَّل في سجل التدقيق — أصلحتُه |

## مرفوض / لم يُدمج
- بوابة `range` المرجعية كما هي (NaN→PASS).
- مطابقة التسمية `VOSA*`/`vosa_*` في TypeScript: المستودع يستخدم `Vosa*` (camelCase) وملفات `lib/vosa/`. السياسة مكتوبة لحزمة Python؛ التغيير يمس واجهات قائمة، فلم أنفذه دون قرارك.

## حالة التحقق
- كود يعمل ومُختبر: 8 اختبارات جديدة (`tests/vosa-integrity.test.ts`) + 17 + 28 = 53 ناجحاً (محوَّلة CJS محلياً).
- **غير مربوط بالإنتاج:** السلسلة والسلالة والسجل (in-memory) تجريبية.
- لا علاقة لهذه الدفعة بتحسين الدقة التنبؤية؛ هي سلامة وتدقيق فقط.
