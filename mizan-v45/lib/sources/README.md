# طبقة مصادر ميزان

مرجع تشغيلي، وليس إثبات اتصال إنتاجي أو اكتمال بيانات.

| الملف | الدور |
|---|---|
| `types.ts` | عقود الأنواع والنتائج والمحاولات والمصدر |
| `registry.ts` | المرشحون ودرجات الطبقات `TIER_SCORE` |
| `endpoints.ts` | بناء الروابط المدعومة فعليًا |
| `resolver.ts` | ترتيب المرشحين المؤهلين حسب الطبقة، لا ترتيب المصفوفة |
| `fallback.ts` | تجربة السلسلة والتحقق بالـparser وتسجيل المحاولات |
| `quality.ts` | تقييم provenance؛ ليس تدقيقًا شاملًا لصحة كل رقم |
| `conflict.ts` | كشف الاختلاف والمفاضلة حسب قوة المصدر |
| `parsers/types.ts` | عقود الماليات والإفصاحات |
| `parsers/sec.ts` | إعادة استخدام محلل SEC الأصلي مع مطابقة CIK |
| `parsers/yahoo.ts` | إعادة استخدام محللات الأسعار والماليات والهوية |
| `parsers/pit.ts` | اشتراط تاريخ نشر صالح؛ لا يطبّق تاريخ قطع بنفسه |
| `parsers/index.ts` | اختيار محلل النوع والمصدر |
| `integration.ts` | `fetchViaSources`: واجهة إضافية تستخدم العقود الموجودة |
| `bridge.ts` | تحليل استجابة جُلبت بالفعل؛ بلا طلب شبكة ثانٍ |
| `cik.ts` | قراءة دليل SEC بالقارئ الممرّر، بلا كاش أو ناقل جديد |

## حدود الربط والقواعد

1. مسار الشركة الأصلي `fetchCompany` و`getRegulatory` و`configuredReader` و`resolveFinancialSources` و`source_status` محفوظ. لا يستبدله `fetchViaSources` تلقائيًا. `source_health` إحصاءات قراءة مساعدة فقط، وليست حكمًا موازيًا على صلاحية البيانات.
2. في التطبيق، مرّر القارئ المعتمد `configuredReader` ليحافظ على إعدادات التعطيل والمصدر وحدود SEC والتسجيل. `upstream` المباشر ليس إثباتًا لتطبيق إعدادات الإنتاج.
3. مع CIK معطى لا يُطلب الدليل. بدونه يُطلب فقط لماليات/إفصاحات السوق الأمريكي؛ فشل القارئ لا يؤدي لتجاوزه بقارئ آخر.
4. عند غياب CIK يستبعد SEC من الروابط القابلة للتنفيذ. يحاول النظام البدائل المدعومة فقط؛ لا بديل Yahoo لإفصاحات SEC. لا تُسجّل محاولة جلب مالية لـSEC لم تحدث. محاولة دليل CIK ليست ضمن `FetchResult.attempts`؛ تظل مراقبة النقل مسؤولية القارئ المعتمد.
5. HTTP 200 لا يكفي. الاختبارات ترفض JSON التالف والماليات/الأسعار الفارغة والهوية المختلفة. المصفوفة الفارغة للأحداث أو الأخبار قد تعني عدم وجود أحداث، وليست مساوية لغياب سعر مطلوب.
6. `sourceTime` المجهول يبقى `null`. تاريخ الإفصاح ليس تأخر سعر حي. درجة provenance وحدها ليست ثقة التوصية أو اكتمال البيانات.
7. Yahoo المالي لا يقدم تاريخ نشر موثقًا في المحلل الحالي؛ يبقى `filedAt: null`. دالة `pitSafe` تشترط النشر، لكن منع المستقبل يحتاج أيضًا تاريخ قطع من المسار الأصلي. لا يُستخدم `fetchViaSources` الحالي كواجهة backtest تاريخية لأنه لا يستقبل `asOf`.
8. يحتفظ النقل الافتراضي بهوية `USER_AGENT` الحالية وخيار التخصيص؛ لا يثبت الاختبار التركيبي قبول SEC لهذا الرأس في الإنتاج.

## التشغيل

بعد تثبيت اعتماديات lockfile:

```sh
npx tsc --noEmit
npm run test:sources
npm test
```

تضم حزمة المصادر اختبارات القبول، واختبارات parsers الأصلية، واختبارات CIK المستقلة. الاختباران الحيان متوقفان افتراضيًا ولا يُحتسبان نجاحًا عند التخطي.

```sh
MIZAN_LIVE_TESTS=1 node --test --import tsx lib/sources/__tests__/live.test.ts
```

التشغيل الحي اختياري ويتصل بالمصدر عبر `upstream` دون الكتابة في D1؛ ليس اختبار جلسة المالك أو Worker الإنتاجي. النتائج وحدود القبول في `docs/sources-acceptance.md`.
