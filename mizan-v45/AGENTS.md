# مرجع العمل على ميزان

اقرأ تعليمات المستخدم في `PROJECT_INSTRUCTIONS.md` قبل تعديل التحليل أو مصادر البيانات أو المخرجات، والتزم بها عند تطوير المشروع.

حفظ النص يوثق المتطلبات ولا يثبت اكتمال تنفيذها. بيّن حدود التنفيذ والتحقق الفعلي، ولا تفترض بيانات أو تفضيلات شخصية أو تصنيفًا شرعيًا غير موثق. تعليمات المستخدم اللاحقة توجه العمل عند تحديث المتطلبات.
