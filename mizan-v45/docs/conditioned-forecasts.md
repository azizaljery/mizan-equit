التغيير الحالي يرفع تعريف نموذج الأسهم إلى `mizan-scenarios-7`، وتبقى السجلات السابقة وإعدادات المستخدم والمحفظة كما هي. تغيير الإصدار يمنع خلط قياس النموذج الجديد بإحصاءات الإصدار السابق.

## المسار المنفذ

`MarketReport → forecastConditions + researchFactors → forecasts → recordAnalysis → Forecasts`

- `lib/forecast-conditions.ts`: أدلة التدفق الحر والحجم النسبي وتصنيف السوق. يستخدم `RegimeState` الموجود؛ لا ينشئ تعريفًا متعارضًا باسم `MarketRegimeResult`، ولا يستورد نوعًا ماليًا غير موجود من غرفة القرار.
- `lib/research-model.ts`: يدمج الشروط في المدد الست الحالية، ومنها الجلسة التالية. يعيد كل صف أدلة `modelCondition` ويُحفظ هذا الحقل مع التوقع عند الإصدار.
- `components/forecasts.tsx`: يعرض أدلة التدفق والسيولة ومصادرها في التفاصيل، وسبب الامتناع القصير ظاهرًا. يظل تقديم `data` أو `report.forecast` المحفوظ أسبق من إنشاء توقع جديد؛ لم يُضف حساب عند قراءة السجلات القديمة.
- `generateCalibratedForecast` واجهة تجميع فوق نفس `forecasts`؛ الاسم للتوافق مع طلب المستخدم، ولا يثبت المعايرة. المخرجات تحمل `calibrated: false`، و`probabilityUp` و`confidenceScore` و`fcfDriftImpact` قيمتها `null`.

```ts
import {generateCalibratedForecast} from './research-model';

const result = generateCalibratedForecast({
  report, // التقرير الحقيقي، مع الأسعار وأحجامها والعملات والبنود ومصادرها وتواريخها
  quote: report.liveQuote ?? null,
  now: Date.now(),
});
const weekly = result.horizons[5];
```

تغيّر عقد `ForecastInput` عمدًا إلى التقرير الكامل بدل الأرقام المفصولة. لا تُرسل نسبة فوز أو Brier أو حالة سوق مفترضة لهذا المدخل. لتقدير تاريخي يمرر تقرير تاريخي حقيقي ووقت القطع في `now`؛ يُتجاهل السعر الحي في الوضع التاريخي. هذه الدالة تنشئ حسابًا جديدًا ولا تحفظه وحدها، وليست بديلًا عن قراءة السجل الثابت.

## ما تغير في الصيغة المرسلة

| الجزء | السلوك المنفذ |
|---|---|
| التدفق الحر | مبلغ مباشر أو CFO − القيمة المطلقة للإنفاق، لنفس السنة والعملة وبعد حل المصادر والوحدات. لا يتحول الإنفاق المفقود إلى صفر. اختلاف المبلغ المباشر والمحسوب يستبعد التدفق الحر وحده. |
| توقيت الأدلة الجديدة | مصدر HTTPS وتاريخ نشر معروف لا يسبق نهاية الفترة ولا يتجاوز وقت القطع، وسنة مالية لا تتجاوز 550 يومًا. نشر اليوم بعد ساعة التقدير لا يدخل في الأثر الجديد. هذه شروط للأدلة الجديدة؛ لا تعني تدقيق كل مصدر في التقرير مرة أخرى. |
| أثر التدفق | نسبة FCF/CFO عند CFO موجب تدخل كمكوّن وصفي محدود بين −1 و1 في عامل الجودة ووزنه الحالي، بشرط تطابق سنة التحليل وعدم تخصص الورقة. بقية عوامل الجودة تبقى مستقلة. ليس هذا معدل نمو سعريًا. |
| عائد FCF | نسبة وصفية فقط، باستخدام عدد أسهم مؤرخ لا يتجاوز 210 أيام × آخر إغلاق صالح. يُستبعد عند وجود تجزئة لاحقة لعدد الأسهم. لا يستخدم مليون سهم افتراضيًا أو قيمة سوقية بلا توقيت. |
| تكلفة رأس المال | لا تُفترض 8.5% ولا يستنتج منها انحراف سعري. حقل `fcfDriftImpact` غير مقدّر. |
| الحجم النسبي | حجم الجلسة / متوسط العشرين السابقة؛ يلزم 21 حجمًا صالحًا، والأحجام السالبة والمفقودة غير مقبولة. النسبة المجهولة تبقى مجهولة. |
| ضعف الحجم | عند RVOL < 1.1 يُضرب الميل الموجب للنموذج في 0.6. لا يُرفع الميل السالب ولا تُمنح أفضلية عند غياب الحجم. قاعدة المستخدم وصفية ولم تثبت جدواها خارج العينة. |
| حالة السوق | إعادة استخدام التصنيف الوصفي الحالي، بعد 60 جلسة صالحة. تصنيف صدمة التقلب أو إشارة الانكسار يوقف مدد 1 و5 و21 جلسة، ويخفض الثقة الوصفية للمدد الأطول. لا تُعرض إشارة كدليل قاطع على انكسار هيكلي. |
| الميل والنطاق | الإبقاء على الميل متعدد العوامل وحدود التذبذب الحالية. لم تُضف زيادة صعود ثابتة لكل جذر جلسة، ولم يُعامل ATR كانحراف معياري معاير. المركز والنطاق ليسا Q50 وQ10/Q90 معايرة للمستقبل. |
| الاحتمال والثقة | لا افتراض Brier=0.21 أو نسبة فوز=0.53؛ سحب عدد نحو 50% لا يثبت المعايرة. تبقى قوة الأدلة الوصفية منفصلة عن إحصاءات النتائج الفعلية في السجل. |
| موعد النهاية | إعادة استخدام `forecastWindow` مع رمز السوق ووقت التقدير. يستثني الجمعة/السبت للسعودي والسبت/الأحد للأمريكي. الموعد تقديري، والعطل والإغلاق المبكر غير متحققين؛ التقييم يعتمد الجلسات الفعلية. |
| المدخلات غير الصالحة | جلسة مكررة أو غير مرتبة أو بعد تاريخ القطع أو سعر غير موجب/غير محدود يمنع إصدار النطاق؛ لا تعاد كتابة السلسلة لإخفاء المشكلة. |

## التحقق والحدود

- تحقق TypeScript نجح.
- الاختبارات الحالية مع ثمانية اختبارات جديدة: 201 اختبار، 200 ناجح، صفر فشل، واحد متجاوز.
- شملت الاختبارات تواريخ النشر والفترات والعملات وتحويل الوحدات، الإنفاق الصفري، تعارض FCF، غياب الأسهم، أثر التجزئة، RVOL، اختلاف تقويم السوقين، الامتناع القصير، حفظ الأدلة مع كل مدة، وبقاء نص سجل الإصدار السابق دون تغيير.
- الاختبارات ببيانات مصطنعة وقاعدة SQLite محلية. لا تثبت دقة توقع أو احتمالات أو تفوقًا استثماريًا. لم يجر تقييم إحصائي جديد على أسعار سوق فعلية، ولم يُضف مصدر شبكة أو اشتراك أو مهمة تلقائية.
- لا يغيّر هذا الدمج شروط قرار الشراء النهائي أو حماية الإدارة، ولا يمنح شراءً آليًا. التوقع والإشارة الوصفية والقرار التنفيذي أشياء منفصلة في النظام.
