# لوحة خطة التنفيذ

تعرض اللوحة مستويات السيناريو القائم مع عملة التقرير، ولا تستبدل مستويات الاختراق بمنطقة تتحرك حول كل سعر حي. يبقى finalDecision المرجع الوحيد للسماح بالشراء؛ افتراضي العرض انتظار.

الحجم النسبي يتطلب الجلسة الحالية و20 جلسة سابقة صالحة، وتطبق عتبة 1.5 قبل تقريب العرض. غياب الأحجام لا يؤكد السيولة. جودة الأرباح والتدفق الحر مأخوذان من التحليل المالي القائم، وتبقى القيم الناقصة null.

لا توجد نسبة فوز افتراضية أو تخصيص أدنى مفروض لحساب كيلي. لا يعرض حجم مركز دون دليل تاريخي مناسب. الأهداف والوقف الحاليان محفوظان؛ لا تحمل الواجهة عبارة 1.8 ATR غير المطابقة لها. لا ضمان لتنفيذ الوقف أو انعدام المخاطر.

الواجهة المرسلة موصولة بعقد TradePlan متوافق مع البيانات الحالية. نموذج generateTradeScenario المرسل سابقًا لم يُفعّل بدل محرك المستويات؛ تتطلب إعادة تصميمه ودليل التحجيم معالجة مستقلة قبل تغيير قرارات التداول.
