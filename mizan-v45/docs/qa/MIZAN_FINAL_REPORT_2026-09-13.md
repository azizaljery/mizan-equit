## ما دُمج وصُحح

- قراءة `research_state` عبر list وkeys وexists وfields وslices، مع حدود أحجام وصفحات، وأسماء حقول مضبوطة ومسارات SQL مربوطة كقيم. حجم النص بالبايت منفصل عن عدد أحرف Unicode. الحقول الكبيرة تعاد null مع سبب حجبها من الملخص، وJSON التالف يوسم صراحة.
- حماية endpoint بهوية المالك **وجلسة إدارة ميزان الحالية**. سكربت التشغيل يستخدم HTTP مباشرة ويرسل Origin الصحيح؛ Cookie الإدارة وحده لا يغني عن جلسة الاستضافة. لا يطبع بيانات الدخول أو يتبع redirects.
- فحص Scheduler يقرأ حقولًا صغيرة من سجل التشغيل، ولا يجعل configured=true بمجرد وجود المعالج أو المفتاح. لم تنشأ `source_health` أو نسخة أخرى من منظومة المصادر أو التوقعات.
- قياس جماعي للتوقعات الأصلية عبر `fetchCompany(configuredReader(...))` ثم `evaluateForecast` القائم، مع حفظ التقرير في `backtest_runs` الحالي وعمود symbol الإلزامي. لا migration جديدة ولا جدول نتائج مكرر. إعادة runId نفسه تعيد التقرير الأصلي، وفشل الحفظ لا يختفي.
- ضبط حدود النوافذ، وعدم تداخلها، والحياد، ومقامات الاتجاه والنطاق والسعر، وفصل MAE بحسب العملة، وربط مقارنة المرجع بالتاريخين نفسيهما. Sharpe التجميعي يعاد من المشاهدات ولا يؤخذ متوسط Sharpe النوافذ.
- هذه مراجعة نوافذ **التوقعات الصادرة**؛ ليست تدريبًا جديدًا أو walk-forward optimization. trainStart/trainEnd يحددان التاريخ السابق ويعرضان عدد سجلاته، مع retrained=false. محرك replay التجريبي القديم محفوظ.
- أُضيف `MIZAN_BACKGROUND_CRON_ENABLED=true` من إعدادات الاستضافة الفعلية، وطُبقت مراجعة البيئة 5 بالنشر. تعريف التعبير الوحيد بقي في إعداد البناء الفعلي. تفعيل المتغير **ليس دليل تسجيل Trigger**.
- لم يحذف أي ملف من المشروع أو سجل إنتاجي. لم تُعدّل وظائف الذهب أو التوصيات أو UI أو كلمات المرور.
