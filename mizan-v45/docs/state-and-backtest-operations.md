# القراءة المحمية وقياس السجل

هذه إضافة إلى ميزان الحالي. `research_state`, `backtest_runs`, `configuredReader`, `fetchCompany`, `evaluateForecast` و`source_status` هي العقود القائمة. لا توجد migration جديدة أو وظيفة حذف في الإضافة.

## قراءة الحالة

`GET /api/admin/state` يتطلب هوية المالك التي تثبتها الاستضافة **وجلسة إدارة ميزان**. Cookie `mizan_admin` وحده لا يثبت هوية الاستضافة. لا تُرسل قيمة البريد في header يدوي لمحاكاة هوية المالك. في المتصفح المسجل دخوله يمكن تنفيذ GET من الأصل نفسه. CLI يرسل Cookie الجلسة الفعلية وOrigin؛ لا يطبع بيانات الدخول ولا يتبع redirect إلى تسجيل الدخول.

اضبط `MIZAN_HOST` على أصل ميزان، و`MIZAN_COOKIE` محليًا من جلسة المالك والإدارة الفعلية. لا تحفظه في Git أو ترسله في المحادثة.

```sh
node scripts/read-prod-state.mjs list 0 20
node scripts/read-prod-state.mjs keys 0 20
node scripts/read-prod-state.mjs exists job:evaluate-due:last-cron
node scripts/read-prod-state.mjs fields job:evaluate-due:last-cron triggeredBy,cron,scheduledTime,status,stateSaved,finishedAt,evaluationsSaved,symbolsScanned,symbolsFailed
node scripts/read-prod-state.mjs slices job:evaluate-due:last-cron 0 4000
```

القائمة والمفاتيح من 1 إلى 100 عنصر؛ استخدم `hasMore` و`offset` للصفحة التالية. `size` بايتات UTF‑8، أما `offset`, `length`, `totalLength`, `nextOffset` في الشرائح فهي **Unicode code points** كما يعدها SQLite، وليست بايتات أو UTF‑16. شريحة 4000 حرف قد تتجاوز 4KB. استخدم `nextOffset` ومرّر `updatedAt` العائد من الشريحة الأولى في القراءات التالية لرصد تغير وقت السجل.

الحقول من 1 إلى 20 اسمًا غير مكرر يبدأ بحرف لاتيني ويحتوي حروفًا/أرقامًا/underscore فقط. المسارات مربوطة كقيم SQL. الكائنات والمصفوفات والنصوص الأكبر من 2048 بايت تعاد `null` مع `_omittedFields`؛ JSON التالف يوسم `_invalidJson`. لا يتم تصحيح البيانات أو حذفها أثناء القراءة. أخطاء القيم تعيد 400، السجل الغائب 404، والدخول 401/403، وفشل قاعدة البيانات 503 دون تفاصيل SQL.

`exists=true` وحقول أرقام ليست وحدها إثبات تشغيل Cron. افحص حقول الحدث ووقت الحفظ، ثم طابقها مع سجل استدعاء الإنتاج والتعبير المسجل. الصفحة لا تستخرج التسجيل من Cloudflare ولا تصنع سجل Cron.

## قياس التوقعات الصادرة

`POST /api/admin/backtest` له حماية المالك والإدارة نفسها، وOrigin مطابق، وجسم JSON لا يتجاوز 12000 بايت. الحد 3 رموز أمريكية/سعودية، 500 سجل لكل رمز في الفترة، و4 نوافذ كحد أقصى. الآفاق من مدد ميزان الست القائمة. السجلات تقرأ في صفحات من 50؛ الكبير أو التالف يستبعد صراحة.

```sh
node scripts/run-backtest.mjs single 2026-07-01 2026-08-31 AAPL MSFT 2222.SR
node scripts/run-backtest.mjs walk-forward /absolute/path/windows.json
```

ملف النوافذ يحتوي `runId`, `symbols`, `horizons` ومصفوفة `windows` بعناصر `trainStart`, `trainEnd`, `testStart`, `testEnd`. يجب أن ينتهي الماضي قبل الاختبار وألا تتداخل فترات الاختبار. اختيار الفترات والرموز يجب أن يسبق قراءة النتائج لتقليل تحيز الاختيار.

القيم الافتراضية للتكاليف **افتراضات اختبار**: 5 bps عمولة و10 bps انزلاق لكل جانب. ليست رسوم Alpaca أو خطة مزود مؤكدة. `doubleSided=false` يطبقها مرة عند الدخول. اضبطها وفق نموذجك الموثق.

تُقاس النسخة الأصلية بواسطة `evaluateForecast`؛ لا تصنع توقعات للماضي ولا تكتب `forecast_outcomes`. يلزم تصنيف `prospective-public` وسياسة القياس الحالية وتطابق العملة والنموذج ووقت الإصدار. حد نهاية الاختبار ملزم، ومرجع جلسات السوق يأتي من التقرير الإنتاجي. لا تخلط نهايات مختلفة للمؤشر والسهم. النقص يبقى pending أو excluded مع السبب.

هذه **مراجعة لنوافذ التوقعات الصادرة**، وليست تدريبًا أو walk-forward optimization. `train*` يحدد التاريخ السابق ويعرض عدد سجلاته فقط؛ `retrained=false`. محرك replay التجريبي السابق و`/api/backtest` محفوظان كما هما. لا يُسمى BUY/WAIT فيهما توقع اتجاه أو دقة لنظام ميزان.

الدقة محسوبة من الاتجاه الأصلي بما فيه الحياد؛ لكل من الاتجاه والنطاق والسعر مقام مستقل. MAE مفصول بالعملة. `meanReturn` عائد الأصل الافتراضي من إغلاق يوم الإصدار بعد التكاليف، وليس ربح توصية. Sharpe عيني غير سنوي، والتجميع يعاد حسابه من المشاهدات لا بمتوسط Sharpe النوافذ. `alpha` فرق عائد مقترن بالتواريخ نفسها، وليس Jensen alpha. لا تدعي هذه المقاييس وجود محفظة مستقلة أو أرشيف PIT غير قابل للتعديل.

الحفظ في `backtest_runs` الموجود يشمل عمود `symbol` وJSON التقرير وتفصيل الآفاق؛ لا حاجة لجدول `backtest_results` مكرر. `runId` ثابت يعيد النتيجة الأصلية، ويرفض اختلاف الإعداد. لتحديث بيانات السوق اختر معرفًا جديدًا. فشل الحفظ يظهر كفشل، ولا يُخفى. قد تبقى تقارير النوافذ المكتملة إن فشلت نافذة لاحقة؛ إعادة المعرف نفسه تستكمل باستخدام النتائج المحفوظة.

تقرير كبير يتجاوز مليون بايت يُرفض ويحتاج فترة أصغر. نتائج الاختبار لا تغيّر إعدادات المصادر أو تحفظ توصيات. اختبارات النقل الحي المحلية تستخدم سجلًا اصطناعيًا موسومًا؛ لا تُنسب دقتها إلى توقعات مستخدمي ميزان.
